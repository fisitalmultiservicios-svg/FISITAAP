Primera actualización: menús reorganizados y roles con permisos configurables.

Si GitHub abre la vista del archivo, pulsa el botón de descarga (Download raw file).

## Instalación

1. Guarda un respaldo completo de los archivos y de la base de datos.
2. Sube y extrae el ZIP en `fisitaap.com`, junto a `index.php`, `app` y `assets`.
3. Entra a FISITAAP con la cuenta MAESTRO y abre https://fisitaap.com/actualizacion-fisitaap/.
4. Sigue las comprobaciones del instalador. Hazlo cuando las cajas estén sin operar.

Lee la guía antes de instalar. Si el instalador señala archivos distintos, conserva el mensaje para preparar una actualización compatible.

Esta entrega incluye menús y roles. La reestructuración completa del PDF, la versión Windows, las ventas sin internet y la sincronización entre cajas siguen pendientes.

El paquete se comprobó con datos de prueba; todavía no se ha instalado en HostGator.
