# FISITAAP Escritorio 1.7.2

Mejora la conexión inicial con la web: explica qué dirección copiar y reemplaza el error «Unexpected token '<' … is not valid JSON» por instrucciones claras. Conserva también la corrección del puerto de impresión ocupado de 1.7.1.

[**Descargar instalador para Windows de 64 bits**](https://raw.githubusercontent.com/fisitalmultiservicios-svg/FISITAAP/main/actualizaciones/1.7.2/FISITAAP-Escritorio-1.7.2-Windows-x64.exe)

## Conectar tu negocio

1. En Windows, escribe **https://fisitaap.com** en Dirección principal de tu aplicación web.
2. Entra en la web con la cuenta del negocio, abre **Administración → Windows y cajas sin internet** y crea un código de conexión nuevo.
3. Copia el **Número de equipo** y el **Código** que muestra la web. Pulsa **Conectar** en Windows.
4. Ingresa con el cajero autorizado, su contraseña local y un nombre distinto para cada caja.

La dirección `https://fisitaap.com/laventanita` abre la tienda. El servicio que conecta Windows está en la aplicación principal `https://fisitaap.com`. Los códigos duran 30 minutos y sirven una vez. Usa el número de equipo que muestra la web junto al código.

Si ya tienes 1.7.1, puedes conectar corrigiendo la dirección sin reinstalar el programa. Para incorporar los mensajes nuevos y la ayuda, cierra FISITAAP e instala 1.7.2 sobre la misma carpeta. Se conservan los datos, las ventas, los respaldos y la configuración.

Esta entrega se instala en Windows. La actualización web sigue siendo [1.7.0-R3](../1.7.0-R3/README.md); no necesitas volver a subirla por este cambio.

Si la dirección principal también devuelve una página, confirma que completaste la instalación de la actualización web, además de subir sus archivos a cPanel. Copia la Dirección web que muestra la pantalla al crear el código.

Para revisar la entrega: [comprobaciones](COMPROBACIONES.md), [código fuente](FUENTES-FISITAAP-Escritorio-1.7.2.zip) y [sumas de verificación](SHA256SUMS.txt).
