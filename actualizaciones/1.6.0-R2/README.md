Guarda un respaldo de archivos y base de datos antes de actualizar. El ZIP admite la copia original revisada y la actualización 1.5.0-R1. Si el instalador muestra archivos «distintos», se detiene para conservar tus cambios.

Tras extraerlo, entra con la cuenta maestro y abre **https://fisitaap.com/actualizacion-fisitaap-r2/**. No reemplaces los archivos de `app` manualmente.

Las cajas Windows se conectan a un equipo central encendido en la misma red del negocio. Pueden buscar y vender mientras falta internet; envían las ventas a la web cuando vuelve la conexión. La gestión de mesas, compras, crédito y FISIChat permanece en la web.

Las pruebas cubrieron la instalación web, permisos, operaciones de negocio, dos cajas sin internet y sincronización real. El `.exe` fue construido, pero su instalación en una computadora Windows real y la impresión en tus equipos todavía deben comprobarse. Usa primero un negocio de prueba. El instalador Windows no tiene firma digital.

Para revisión técnica: [alcance y comprobaciones](COMPROBACIONES.md), [fuentes del escritorio](FUENTES-FISITAAP-Escritorio-1.6.0.zip) y [sumas de verificación](SHA256SUMS.txt).
